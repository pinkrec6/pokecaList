# pokecaList — ポケカ一覧ビューア（スタンダードレギュレーション）

[ポケモンカード公式のカード検索](https://www.pokemon-card.com/card-search/) から
スタンダードレギュレーションの全カードを取得し、Excelのオートフィルタのような
操作でカードを絞り込めるローカルWebアプリです。

## 必要環境

- Python 3.8 以上（標準ライブラリのみ使用。追加インストール不要）

## 使い方

1. `start.bat` をダブルクリック（または `python server.py`）
   → ブラウザで http://127.0.0.1:8787/ が開きます
2. 初回は右上の **「🔄 更新」** ボタンを押してカードデータを取得します
   - 初回は全カード（約5,400枚）の詳細を取得するため **1時間程度** かかります
     （公式サイトのレート制限に配慮し、リクエスト間隔を約0.6秒に制限しているため）
   - 2回目以降は **差分（新カード追加・スタン落ち削除）のみ** 取得するので数分で終わります
   - 更新完了後、追加・削除されたカードの一覧が表示されます（「前回の差分」ボタンで再表示可）

## 画面の機能

- **タブ**: ポケモン／トレーナーズ／特殊エネルギー を切り替え
- **列フィルタ**: 各列見出しの「▼」からExcel風に絞り込み
  - テキスト列 … 部分一致（スペース区切りでAND検索）
  - 区分・タイプなどの列 … チェックボックスで値を選択
  - HP … 最小〜最大の範囲指定
- **ソート**: 列見出しのラベルをクリック（昇順→降順→解除）
- **全文検索**: 右上の検索ボックスで全項目を横断検索
- **行クリック**: カード画像と詳細、公式ページへのリンクを表示

### 列の内容

| タブ | 列 |
|---|---|
| ポケモン | 区分（たね/1進化/2進化）、ポケモン名、タイプ、HP、特性名、特性効果、技1・技2（エネ/名前/ダメージ/効果）、弱点、抵抗力、逃げエネ、レギュレーション（収録シリーズ記号） |
| トレーナーズ | 区分（グッズ/ポケモンのどうぐ/サポート/スタジアム）、カード名、効果、レギュレーション |
| 特殊エネルギー | エネルギー名、タイプ、効果、レギュレーション |

## ファイル構成

```
scraper.py   … 公式サイトからカード情報を取得・パース（差分更新）
server.py    … ローカルWebサーバー（/api/cards, /api/update, /api/status）
web/         … フロントエンド（index.html / app.js / style.css）
data/cards.json … 取得したカードデータ（自動生成）
```

## コマンドラインでの更新

サーバーを立てずにデータだけ更新することもできます:

```
python -X utf8 scraper.py            # 差分更新
python -X utf8 scraper.py --limit 30 # テスト用（新規30枚まで）
```
